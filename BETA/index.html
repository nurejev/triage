    About this BETA

    This is a browser port of the Microsoft-Analyzer-Suite (MAS) by LETHAL-FORENSICS. MAS is a set of PowerShell analyzers that read Microsoft-Extractor-Suite exports and produce styled Excel workbooks. This BETA reimplements its detection rules in the browser, adds a live Graph collector so you don't have to extract first, and renders an interactive report instead of Excel.

    What it covers

    The Core BEC set — EntraSignInLogs, EntraAuditLogs, the Unified Audit Log, RiskyUsers & RiskyDetections, and OAuthPermissions — plus the Inventory set (Users, Devices, Admins) and an MFA-coverage view. The blacklists (ASN, country, user-agent, application, risky permission) are the MAS lists, regenerated from their repo.

    What stays import-only

    Message Trace, Transport Rules, Mailbox Permissions and Mailbox Audit Status are Exchange-Online-only and can't be reached from a browser. Import an Extractor-Suite export to analyze them (message-trace analysis lands in a later build).

    Two ways in

    Live scan pulls the whole tenant window from Graph with read-only delegated permissions. Import parses Extractor-Suite CSV/JSON in your browser. Both run the same engine and produce the same report.
